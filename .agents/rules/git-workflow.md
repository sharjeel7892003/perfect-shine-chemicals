# Git Auto-Commit & Push Standing Rule

After completing ANY code change, fix, or new feature in this repository, always automatically:
1. Commit the changes with a clear, descriptive commit message explaining what was changed.
2. Push the commit to GitHub immediately (`git push`).
3. Confirm the push was successful and mention the commit message/summary to the user, so they know it is live and ready to test on `perfect-shine-chemicals.vercel.app`.

Treat pushing to GitHub as the final, required step of completing any task—do not wait for the user to prompt or ask for it. If a push fails for any reason, notify the user immediately.
